GOOD TO KNOW

Frequently asked questions

Are these PDF tools free?

Yes. This starter version is free to use and does not require an account.

Are my documents uploaded?

No. File processing is performed in your browser. The page loads its JavaScript libraries from public CDNs, but your selected files are not sent to those services.

Will compression always make my PDF smaller?

Not always. The compression tool re-renders pages as images, which can reduce file size but may lower quality and remove selectable text. Always compare the output with the original.

Can I convert PDF to editable Word?

That feature is not included in this starter version because reliable PDF-to-Word conversion needs more advanced conversion logic. This site is structured so more tools can be added later.
